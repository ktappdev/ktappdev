## Selected work

A few products and tools I have built for real problems, not a collection of demos.

- **[ReviewIt.gy](https://reviewit.gy)**: A review platform for Guyanese consumers and local businesses.
- **[Lyricut](https://lyricut.com)**: Analyzes song lyrics, flags explicit phrases, and produces actionable reports for broadcasters, DJs, and producers.
- **[SSH Thing](https://github.com/ktappdev/ssh-thing)**: A focused, cross-platform SSH client with a Rust and Tauri backend.
- **[Hitman](https://github.com/ktappdev/hitman)**: A dark-themed Go TUI for finding and stopping processes by port.
- **[Maad Radio](https://www.maad97.com/)**: A radio platform with live audio/video streams, schedules, and station integrations.

## Open source & experiments

- **[contexting](https://github.com/ktappdev/contexting)**: Fast, deterministic codebase indexing for LLM agents.
- **[fromai](https://github.com/ktappdev/fromai)**: An AI-powered coding task manager built with SvelteKit and PocketBase.
- **[pi-windsurf](https://github.com/ktappdev/pi-windsurf)**: Windsurf/Cognition models for the Pi coding agent.
- **[cicd-thing](https://github.com/ktappdev/cicd-thing)**: Push-to-deploy CI/CD for websites and apps.

## How I build

I reach for **Go** when systems need to be fast and dependable, **Rust** when correctness and small binaries matter, and **TypeScript** when product surfaces need to move quickly. Around that core: React, Astro, PocketBase, PostgreSQL, Docker, and self-hosted infrastructure.
